# Tesnim.de - Deutsch-Uigurisches Wörterbuch (V2)

Tesnim ist eine moderne Web-Applikation, die als Brücke zwischen der deutschen und uigurischen Sprache dient. Ziel des Projekts ist es, ein umfangreiches, digitales Wörterbuch bereitzustellen, das durch KI-Technologie unterstützt wird, um Sprachbarrieren abzubauen und die uigurische Sprache im deutschsprachigen Raum zu fördern.

## 🚀 Features (In Entwicklung)

- **Bidirektionale Suche:** Suchen Sie Wörter sowohl von Deutsch nach Uigurisch als auch von Uigurisch nach Deutsch.
- **KI-Unterstützung:** Integration der Google Gemini API zur Generierung von Beispielsätzen, grammatikalischen Erklärungen und Übersetzungen für Wörter, die noch nicht in der Datenbank vorhanden sind.
- **Dynamische Datenbank:** Automatische Erweiterung des Wortschatzes durch Speicherung von KI-generierten Ergebnissen in Google Firebase.
- **TypeScript & React:** Eine stabile und performante Codebasis für ein flüssiges Nutzererlebnis.

## 🛠 Tech Stack

- **Frontend:** [React](https://reactjs.org/) mit [Vite](https://vitejs.dev/)
- **Sprache:** [TypeScript](https://www.typescriptlang.org/)
- **Backend/Datenbank:** [Google Firebase](https://firebase.google.com/) (Firestore & Auth)
- **KI-Modell:** [Google Gemini API](https://ai.google.dev/)
- **Styling:** Tailwind CSS (oder dein verwendetes Framework)
